## 1. Зорилго

Энэхүү лабораторийн ажлаар Mockito сан ашиглан Java програмын Unit Test бичиж сурсан. Мөн Mock объект үүсгэж, програмын үйл ажиллагааг тус тусад нь шалгасан.

- Java 17
- Apache Maven
- JUnit 5

- Ubuntu Linux

## 3. Хийж гүйцэтгэсэн ажил

Нийт 8 төрлийн шалгалт хийсэн. A8 шалгалтад Parameterized Test ашиглан 3 өөр нөхцөлийг шалгасан. Ингэснээр нийт 10 тест ажилласан.

| Тест | Шалгасан нөхцөл |
|---|---|
| A1 | Идэвхтэй оюутан амжилттай бүртгүүлэх |
| A2 | Идэвхгүй оюутан бүртгүүлэх боломжгүй |
| A3 | Оюутан олдоогүй үед алдаа буцаах |
| A4 | Өмнөх холбоо хичээл дутуу үед бүртгэхгүй байх |
| A5 | Имэйл илгээхэд алдаа гарсан ч бүртгэл амжилттай байх |
| A6 | Null утга орж ирэхэд алдаа үүсгэх |
| A7 | ArgumentCaptor ашиглан имэйлийн агуулгыг шалгах |
| A8 | Parameterized Test ашиглан 3 алдааны нөхцөлийг шалгах |

## 4. Mockito ашигласан байдал

Mockito-ийн `@Mock` ашиглан `StudentRepository`, `EmailSender` объектуудыг Mock болгосон.

- `when().thenReturn()` ашиглан буцаах утгыг тохируулсан.
- `verify()` ашиглан функц дуудагдсан эсэхийг шалгасан.
- `never()` ашиглан тодорхой үйлдэл хийгдээгүй эсэхийг шалгасан.
- `verifyNoInteractions()` ашиглан объекттой харилцсан эсэхийг шалгасан.
- `ArgumentCaptor` ашиглан имэйлийн агуулгыг шалгасан.
- `lenient()` ашиглан Parameterized Test-ийн зарим нөхцөлд ашиглагдахгүй stubbing-ийн анхааруулгыг зохицуулсан.

|---|---:|
| Нийт тест | 10 |
| Амжилттай | 10 |
| Алдаатай | 0 |
| Алгассан | 0 |
| Build | SUCCESS |

Үр дүнг `results/mvn-test.txt` файлд хадгалсан.

## 6. Mutation Testing

Програмын үндсэн кодод 3 өөрчлөлт хийж, тестүүд алдааг илрүүлж чадаж байгаа эсэхийг шалгасан.

| № | Хийсэн өөрчлөлт | Тестийн үр дүн |
|---|---|---|
| 1 | Идэвхгүй оюутны шалгалтыг comment болгосон | 2 тест алдаа илрүүлсэн |
| 2 | `saveRegistration()` үйлдлийг comment болгосон | 2 тест алдаа илрүүлсэн |
| 3 | `courseId == null` шалгалтыг хассан | 1 тест алдаа илрүүлсэн |

Гурван тохиолдолд бүгдэд нь тест алдааг илрүүлж `BUILD FAILURE` болсон. Туршилт бүрийн дараа үндсэн кодыг буцааж сэргээсэн.

Mutation Testing-ийн үр дүнг `results/` хавтсанд хадгалсан.

## 7. Дүгнэлт

Энэ лабораторийн ажлаар Mockito ашиглан Unit Test бичиж сурлаа. Mock объект ашигласнаар гаднын сангаас хамааралгүйгээр тест хийх боломжтойг ойлгосон. `when`, `verify`, `ArgumentCaptor` зэрэг Mockito-ийн боломжуудыг ашиглаж үзсэн. Parameterized Test ашиглан олон нөхцөлийг нэг тестийн аргаар шалгасан. Мөн Mutation Testing хийж, бичсэн тестүүд кодын өөрчлөлтөөс үүссэн алдааг илрүүлж байгааг шалгасан. Эцэст нь нийт 10 тестийг амжилттай ажиллуулж, үндсэн кодыг хэвийн байдалд сэргээсэн.
